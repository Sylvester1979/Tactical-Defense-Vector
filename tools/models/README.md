# Procedural 3D models (Blender)

Game models are generated by Python scripts that drive Blender, so every model is
reproducible and reviewable as code. Each `build_<name>.py` writes:

- `<name>.glb` — the game asset (copy into `public/models/`)
- `<name>.blend` — the same model plus a render stage (camera, lights, floor) for review

## Requirements

Either a Blender install, or Blender as a Python module:

```bash
python3.13 -m venv .blender-venv          # bpy 5.2 needs Python 3.13
.blender-venv/bin/pip install bpy==5.2.2
```

## Build a model

```bash
.blender-venv/bin/python tools/models/build_vulcan.py out/
# or: blender -b -P tools/models/build_vulcan.py -- out/
cp out/vulcan.glb public/models/
```

Building also **weathers and bakes** the model (`bake.py`): worn edges, grime in crevices, streaks,
dust on top surfaces and ambient occlusion are baked by Cycles into a colour map and an ORM map
(R = occlusion, G = roughness, B = metallic) per mesh, exported as WebP inside the glb. Emissive
materials stay untextured so the game can recolour them. This takes a few minutes per model:

- `--no-bake` skips it (fast iteration on shapes; the glb gets plain materials),
- `--bake-preview` bakes small and noisy in about a minute (to judge the weathering).

```bash
.blender-venv/bin/python tools/models/build_vulcan.py out/ --bake-preview
```

## Render it for review

```bash
blender -b out/vulcan.blend -P tools/models/render_turntable.py -- renders/ 8 96
# or: .blender-venv/bin/python tools/models/render_turntable.py renders/ 8 96 --blend out/vulcan.blend
```

Arguments: output folder, number of angles around the model (default 8), Cycles samples
(default 96). Also writes a close-up of the turret.

## Model contract

- 1 Blender unit = 1 game 3D unit (10 game px); Z up in Blender (exported as Y up).
- Barrel / forward axis is **+X**.
- Moving parts are Empties the game looks up by name: `Yaw` (turns to target),
  `Pitch` (tilts the guns), `Recoil` (slides back on fire), `Spin` (rotary barrels),
  `Muzzle` (where shots start).
- The material named `Glow` is the tower's energy band; the game recolours and pulses it per tower.
- Enemies: `+X` forward; `Rotor_*` empties spin; emissive materials are named `Enemy*`.
